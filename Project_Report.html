1. Problem Definition

Alberto Watch Company is a full-service watch repair, appraisal and retail store based in Nigeria. The company offers an unparalleled selection of luxury timepieces with first-class service since 1962. Their product range includes brands such as Michael Kors, Rolex, Citizen Eco-Drive, and Bulova, as well as their own Alberto house collection spanning Vintage, Luxury, Smart Watches, Sport, and Clocks.

The company required a modern, professional online presence to:

  • Showcase their full product catalogue across all product line-ups
  • Display pricing transparently in Nigerian Naira (₦)
  • Allow customers to locate the four Nigerian store branches
  • Provide detailed information on watch technology
  • Enable customers to book repairs, appraisals and contact the company online
  • Display a live scrolling ticker with current date, time and geolocation (HTML5)
  • Track and display a visitor count

The solution required a Single-Page Application (SPA) — responsive, cross-browser compatible, and fully operational without any server or database.

2. Objectives of the Project

The objective of this project is to create a real-life, functional website for Alberto Watch Company using core web technologies as specified in the eProject brief. The specific objectives are:

  1. Design and build a responsive Single-Page Application using HTML5, CSS3 and Vanilla JavaScript
  2. Implement all required sections: Home, Products, Technology, Store Locator, Price List, Gallery, Support, About Us, Contact Us, and Site Map
  3. Use a JSON file as the data store for all products, stores, technology and FAQ content
  4. Demonstrate HTML5 features including Geolocation API, localStorage, semantic tags, and form validation
  5. Ensure the site works correctly in Chrome, Edge, Firefox and Safari
  6. Apply attractive fonts, colours and animations as required
  7. Localise the site fully for the Nigerian market (₦ Naira, Nigerian store locations)

6. Source Code Overview

6.1 index.html

A single HTML5 file containing all ten sections. All sections are always visible — the page scrolls continuously. No hidden pages or reloads.

Key HTML5 features used:

  • Semantic elements: <header>, <nav>, <section>, <footer>, <article>
  • <form novalidate> with custom JavaScript validation
  • aria-* attributes throughout for screen reader accessibility
  • loading="lazy" on all non-hero images for performance
  • role="dialog" and aria-modal="true" on popup windows
  • Responsive <meta name="viewport">

6.2 css/style.css (~550 lines)

  • CSS Custom Properties — colour system defined as variables in :root
  • CSS Grid — hero split layout, product card grid, feature strip, two-column sections
  • Flexbox — navigation bar, top bar, card layouts
  • CSS Transitions & Animations — hover effects, modal spring (cubic-bezier), ticker scroll, clock dot pulse
  • @media queries at 960px, 700px, 420px for full responsiveness
  • prefers-reduced-motion media query for accessibility compliance

6.3 js/app.js (~380 lines)

Written as an IIFE (Immediately Invoked Function Expression) — ES5 compatible, no frameworks.

FunctionPurpose
loadData()Fetches products.json; falls back to embedded data.js on file:// protocol
renderFilters()Builds category filter chip buttons from JSON categories array
renderProducts()Renders the product card grid; re-renders on filter change with fade
card(p)Returns HTML string for a single product card
openProduct(id)Finds product by id, populates modal, calls showModal()
renderTech()Renders the six technology cards with images
renderStores(city)Renders store cards; highlights nearest city if provided
nearestStore(lat,lng)Haversine formula to find closest store to user's GPS coordinates
initPrices()Price table with live search, category filter and A-Z / price sort
initGallery()Photo grid; click opens lightbox modal
initFAQ()Accordion expand/collapse for FAQ items
validateForm()Client-side validation — checks required fields and email format
initHeroClock()Draws SVG tick marks; animates hour, minute, second hands every second
initVisitors()Reads visitor count from localStorage, increments once per session
initTicker()Updates scrolling ticker with live date, time and geolocation every second
initScrollSpy()Adds/removes .active class on nav links as user scrolls past sections
showModal() / hideModal()Spring-animated modal open/close with keyboard (Esc) and backdrop support

6.4 data/products.json

The JSON data store has five top-level keys:

  • categories — array of 5 product line-up names
  • products — 15 objects: id, name, brand, category, price (₦), description, specs
  • stores — 4 Nigerian store objects: city, address, phone, lat, lng, hours
  • technology — 6 objects: title, icon, description text
  • faq — 5 objects: question, answer

9. Assumptions

  1. Visitor count is stored in the browser's localStorage. It starts at 1,250 and increments by 1 per new browser session. It does not sync across different browsers or devices — this would require a server.
  2. Prices are approximate market prices in Nigerian Naira (₦) for demonstration purposes only. They do not represent real retail prices.
  3. Store addresses and phone numbers are sample data created for the purpose of this project.
  4. Geolocation uses the browser's HTML5 Geolocation API. If the user denies location permission, the ticker falls back to displaying the user's detected time zone instead of coordinates.
  5. Form submissions are simulated client-side only. No email is actually sent. A real deployment would require a server-side form handler or a third-party service such as EmailJS or Formspree.
  6. No external libraries were used — no jQuery, no React, no Bootstrap, no AngularJS. The entire site is built with pure HTML5, CSS3 and Vanilla JavaScript as required by the brief.
  7. The site is designed to work fully offline once the files are saved locally, as all images and data are bundled with the project.
